Workflow Rescue: check an n8n export before import

ELYREON Workflow Rescue finds broken connections, duplicate node IDs, disabled nodes and configuration risks. It returns structured findings, evidence, repair suggestions and an input hash. It performs static analysis; it does not execute workflow code or verify runtime behavior.

Try it free

Send only a sanitized export you are permitted to share. No payment, wallet or fleet account is required. Limits: 20 calls per client per day, 64 KiB per request and 200 nodes. Shared limits also apply.

curl https://elyraon.com.co/agents/trial \
  -H 'Content-Type: application/json' \
  -d '{"source":"direct_api","campaign":"first-check"}'

# Keep the returned token private. Wrap your export as {"workflow": ...}.
curl https://elyraon.com.co/agents/check \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: first-check-001' \
  --data-binary @sanitized-request.json

The result contains structural_pass, report.findings, report.limitations, receipt_id and input_sha256. A successful check can find a defective workflow. Runtime risks remain explicitly unverified.

Payload Validator: check JSON before an API call

Validate sanitized JSON against a bounded JSON Schema 2020-12 subset and receive PASS, FAIL, or REJECTED with a structured error and receipt. Unsupported schemas are rejected explicitly. No references, regex, formats or combinators.

Payload Validator skill and limits · Install and run a first check

curl https://elyreon-payload-validator.colt2822.workers.dev/trial \
  -H 'Content-Type: application/json' -d '{"source":"direct"}'

curl https://elyreon-payload-validator.colt2822.workers.dev/validate \
  -H 'Content-Type: application/json' -H 'Authorization: Bearer YOUR_TOKEN' \
  -d '{"schema":{"type":"object","required":["id"],"properties":{"id":{"type":"integer"}}},"payload":{"id":42}}'

Save your token privately and reuse it after the next edit. Each service has a separate token and a free limit of 20 calls/token/day. Controlled evaluations must enroll with "test":true.

Privacy and price

Requests and reports are processed transiently and are not retained. Operational telemetry contains opaque client IDs, client-claimed source, call outcomes and timing. Operational records expire after 30 days; source claims do not establish verified adoption. Keep credentials and private information out of shared exports. A local browser version keeps your export on your device.

The trial is free. A candidate price of $0.01/call for higher-volume use is under evaluation; no paid endpoint or payment collection is active. Paid availability requires approved terms, receiving-account verification and settlement reconciliation.
